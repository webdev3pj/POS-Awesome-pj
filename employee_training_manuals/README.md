# Employee Training Manuals (Simple Pack)

This folder contains very simple staff manuals for each POS role.

## Files

- `src/01-sales-associate-manual.md`
- `src/02-cashier-manual.md`
- `src/03-picker-manual.md`
- `src/04-dispatch-manual.md`
- `src/05-supervisor-manual.md`
- `src/06-process-overview.md`

## Build PDFs

Run:

```powershell
python employee_training_manuals/build_pdfs.py
```

Output PDFs are written to:

- `employee_training_manuals/pdf/`
